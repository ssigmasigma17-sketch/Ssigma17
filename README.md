# Camera

Веб-приложение в виде камеры телефона: вместо изображения с камеры играет ваше видео.
Удобно для записи экрана, розыгрышей и демонстраций.

## Что умеет

- Режимы ФОТО и ВИДЕО с переключателем внизу, свайп по экрану тоже переключает режим.
- Зум 0,5 / 1× / 2 и щипок двумя пальцами.
- Спуск затвора со вспышкой-морганием и звуком; запись видео с красным таймером, паузой и снимком во время записи.
- Касание экрана ставит жёлтую рамку фокуса, движение пальцем вверх-вниз меняет яркость, долгое нажатие блокирует фокус.
- Переворот камеры с анимацией: отдельное видео для фронтальной камеры.
- Таймер 3 и 10 секунд, сетка, миниатюра последнего снимка и просмотр снимков.

## Настройки

Удерживайте палец на самом верху экрана около секунды. Там можно добавить видео для задней и фронтальной камеры,
картинку для миниатюры галереи и включить повтор, запуск с начала и приближение в режиме видео.
Видео хранятся только в браузере телефона (IndexedDB) и никуда не отправляются.

## Установка на iPhone

1. Опубликуйте папку на любом HTTPS-хостинге (например, GitHub Pages: Settings → Pages → Deploy from a branch).
2. Откройте ссылку в Safari → «Поделиться» → «На экран „Домой“».
3. Запускайте с иконки: приложение откроется на весь экран.

Файлы: `index.html` (всё приложение), `manifest.webmanifest`, `sw.js` (офлайн-кэш), `icons/`.

## Дашборд тривоги (Житомир): `dashboard/`

Одна сторінка для телефону: карта dimap.live (або NEPTUN) на весь екран, знизу шторка зі статусом.

- **Статус** — офіційні тривоги по районах з API [NEPTUN](https://neptun.in.ua/developers) (у браузері, без ключів);
  рівень і тип загрози — з репостів офіційних сповіщень у місцевих каналах. Без NEPTUN статус береться з каналів.
- **Цілі** — живі цілі NEPTUN у радіусі 250 км: відстань і напрямок від Житомира, курс на місто й час підльоту, радар. На радарі в кожного типу свій силует (шахед, крилата ракета, балістика, КАБ, МіГ-31К, розвідник, невідома ціль), повернутий за курсом, а під радаром — скільки яких цілей. Радіус радара — «Авто» (наближає, коли ціль близько) або 50/100/200 км; торкніться цілі на радарі чи в списку — під радаром з’являться деталі. У налаштуваннях можна ввімкнути короткий сигнал, коли нова ціль летить на ваше місце.
- **Тривоги → За тиждень** — скільки часу тривоги тривали кожного дня і в які години доби вони бувають найчастіше (торкніться стовпчика чи години). Історію зберігає збирач (8 днів).
- **Шлях цілі** — на радарі лінія, де ціль пролетіла за останні ~25 хв (за звітами NEPTUN), пунктир — від останнього звіту до оцінки «зараз».
- **Стрічка → Вибухи / ППО** — де були вибухи чи працювала ППО за добу або тиждень, по місцях; торкніться місця — лишаться лише його повідомлення. Збирач зберігає такі повідомлення 7 днів (`hits` у events.json).
- Шрифт Manrope лежить разом зі сторінкою (`dashboard/fonts`).
- **Без інтернету** сторінка відкривається з останньої збереженої копії (`dashboard/sw.js`) і показує останні дані з позначкою часу; цілі NEPTUN — лише якщо їм менше 30 хв.
- **Стрічка** — пости Telegram-каналів про Житомирщину: курс, увага, вибухи, ППО, «чисто»; однакові з кількох каналів об'єднано.
- **Тривоги** — графік тривог у Житомирі за добу, стан районів, стан джерел.
- **Моє місце** (⚙︎ або «Відстані від» у «Цілях»): GPS, пошук міста / села / адреси (OpenStreetMap Nominatim — лише
  за кнопкою, не частіше разу на секунду, як вимагають його правила), координати «50.25, 28.66» або швидкий вибір міста.
  Від нього рахуються відстані, курс «на вас», час підльоту, радар і статус тривоги у вашому районі. Зберігається лише в браузері.
- Налаштування: звук на початок тривоги, сповіщення браузера (Android/ПК), вибір карти.

Дані з каналів збирають:
- `worker/` — Cloudflare Worker, читає канали на кожен запит (живе джерело, ~15 с);
- `.github/workflows/feed.yml` + `scripts/collect.mjs` — щохвилини в GitHub Actions, зберігає стан районів та історію
  в `dashboard/events.json` на гілці `gh-pages` (публікує не частіше ніж раз на 6 хв через ліміт збірок GitHub Pages).

Розбір каналів — `worker/index.js`, перевірка на реальних постах — `node worker/test.mjs`.
Свіжу вибірку постів для налаштування розбору дає ручний workflow «Corpus» (гілка `corpus`).
Код Worker також лежить у репозиторії `zhytomyr-events`, з якого його розгортає Cloudflare; після змін у `worker/`
його треба оновити і там.
